# The Kappa Alpha Literary Society at the University of Western Ontario

## Website Concept for VOO, London, Ontario

This concept is for the University of Western Ontario chapter of the Kappa Alpha Literary Society, known locally as VOO. It is not a national Kappa Alpha Society website. The site should feel like a serious chapter hub for students, alumni, parents, community members, and prospective members.

The tone should be elegant, literary, warm, credible, and grounded in chapter life at the University of Western Ontario. The site should avoid generic fraternity tropes, party-forward language, hype-page energy, and an overdone secret society aesthetic. VOO should come across as a local institution with a long memory: serious about conversation, brotherhood, alumni tradition, events, and life at the Lodge.

## 6. Admin Portal Screen Plan

The admin portal should be simple, calm, and officer-friendly. It should help the chapter keep the public website current without forcing officers into technical decisions. This is a user experience concept only and does not specify a database, payment processor, hosting provider, authentication system, or backend architecture.

### Dashboard

Purpose: Give officers a quick view of what needs attention.

Screen elements:

- Upcoming events summary
- Draft news posts
- New submitted questions
- Featured homepage content status
- Recently updated leadership cards
- Quick actions: Add Event, Write Chapter Letter, Review Questions, Update Homepage

### Events Manager

Purpose: Add, edit, feature, and archive events.

Capabilities:

- Add / edit upcoming events
- Set event title, date, time, location, audience, type, and description
- Mark an event as featured on the homepage
- Add event image placeholder
- Move past events into the archive
- Add event recaps after completion

### Event Recaps

Purpose: Preserve memory and show activity.

Capabilities:

- Add recap title
- Attach photos or gallery placeholders
- Write short summary
- Tag event type
- Link recap to original event
- Publish to News / Chapter Letters or Past Events Archive

### Questions Inbox

Purpose: Centralize public questions and turn strong ones into FAQs.

Capabilities:

- View submitted questions by topic
- Mark questions as new, in review, answered, archived, or FAQ candidate
- Add internal officer notes
- Draft a public answer
- Publish approved questions to the public FAQ

### News / Chapter Letters Manager

Purpose: Keep chapter updates consistent.

Capabilities:

- Add / edit news posts
- Select content type: Chapter Letter, Event Recap, Alumni Profile, Lodge Update, Brother Spotlight, Chapter Report
- Save drafts
- Publish updates
- Feature a post on the homepage
- Archive by month / year

### Leadership Manager

Purpose: Keep officer information current.

Capabilities:

- Add / edit officer cards
- Upload or select photo placeholder
- Set name, role, short bio, and contact placeholder
- Reorder officer cards
- Hide vacant or transitional roles

### Gallery Manager

Purpose: Organize chapter imagery.

Capabilities:

- Add / edit gallery photos

- Categorize by Lodge, Events, Alumni, Formal, Archive, Campus
- Add captions
- Mark photos for homepage use
- Retire outdated images without deleting chapter history

### Support Page Editor

Purpose: Keep support messaging accurate and tasteful.

Capabilities:

- Edit support page introduction
- Update funding priorities
- Update support option descriptions
- Feature current needs, such as Lodge upkeep or chapter programming
- Edit stewardship note

### Homepage Manager

Purpose: Let officers keep the homepage fresh without redesigning the site.

Capabilities:

- Choose featured events
- Choose featured news post
- Select homepage gallery images
- Update alumni / supporter message
- Update social media callout
- Preview homepage sections before publishing

## 8. Visual Direction

Palette:

- Western Ontario purple
- Deep plum
- Ivory
- Charcoal
- Warm gold accents

Typography:

- Serif headings with literary character
- Clean, readable body text
- Avoid overly ornate or theatrical fonts

Imagery:

- Archival-style chapter photography
- Lodge details: wood, books, table settings, old programs, exterior details
- University of Western Ontario campus imagery
- Formal chapter photos
- Alumni gatherings
- Event candids that feel composed and respectful

Design principles:

- Elegant but normal
- Warm rather than mysterious
- Credible rather than promotional
- Literary without becoming costume-like
- Easy for officers to update

Avoid:

- Neon palettes
- Club-promo layouts
- Excessive secrecy symbols
- Cheesy fraternity stock photography
- Overwrought Latin, candles, masks, or occult visual cues
- Aggressive recruitment language
