# VOO Website Concept

Concept package for the University of Western Ontario chapter of the Kappa Alpha Literary Society, also known as VOO, in London, Ontario.

The main deliverable is `VOO-website-concept.md`, which includes the sitemap, homepage wireframe, page-by-page content plan, homepage copy, admin portal concept, visual direction, and asset checklist.

This is a conceptual and non-technical planning document. It does not choose a database, payment provider, hosting platform, authentication system, or backend architecture.
